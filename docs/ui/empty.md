# Empty

`src/ui/components/ui/states.tsx`

Nothing to show: a title, one line, at most one action.

## Props

- `title`, `line`, `action`, `className`.

## Use

- The copy says which empty it is: "No events ingested yet." is not "No events in this range."

## Do not

- Add a second action or a paragraph.
- Use it while loading. That is Skeleton.

## Keys and access

The action is a Button.

## Motion

None.
