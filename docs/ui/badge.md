# Badge

`src/ui/components/ui/badge.tsx`

A level, nothing else.

## Props

- `variant` — `debug` | `info` | `warn` | `error` | `fatal` (and `default`, `secondary`, `outline`).

## Use

- `xs` 18 high, `2xs` type, `rounded-sm`, on the `--level-*` colours.

## Do not

- Use a level badge for the state of a monitor or a share. Use a state colour (`danger`, `warn`, `ok`, `info`).

## Keys and access

Text, not colour alone: the level is written.

## Motion

None.
