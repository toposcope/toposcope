# Switch

`src/ui/components/ui/switch.tsx`

A setting that applies at once.

## Props

- `checked`, `onCheckedChange`, `disabled` (Radix Switch).

## Use

- Live, Count format, Timestamps.

## Do not

- Use a Switch for an action that needs a confirm. That is Button (and Armed).

## Keys and access

Space. It has a visible label or `aria-label`.

## Motion

The thumb slides; reduced motion: none.
