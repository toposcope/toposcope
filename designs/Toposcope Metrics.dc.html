Apps now send OpenTelemetry metrics straight in: sixty names, long ones, of three kinds. This sheet draws one change to one control. The Series menu becomes a list you can type into, that names each metric’s kind, and that puts a histogram’s reading where a log field’s reducer already sits. Same slot, same 26px, same one series per card. Not a metrics browser, not a tree, not a second query language — the search bar still only searches logs. Drawn states, not one happy path.
