lookup Exact match only, fast: ids and request ids. The value is never summarised and never a facet.
ignore Stored with the row, shown in the detail, but no summary and no facet. The default for a key nobody chose.

Toposcope · the principles behind the boards

2026-10-26 · round 3 · every screen not drawn follows these

01The mark is the spine

The first question is since what?, not what matches?. Home answers it with cards; the hunt keeps the same mark selected; a quiet day falls back to the hour before, said plainly.

02One clock, full width

The histogram is the spine of the hunt and the same plot at every size: card sparkline, hunt clock, embed. Marks sit on their own rail with names, never as unlabeled glyphs in a 22px lane.

03Headline features in the open

Compare is a fold under the mark, Fingerprints a line on the event and chips in the slice, Watch this a button on the hunt. Nothing a release note brags about lives in a popover.

04Words, not icons

Tabs, actions and kinds are words: Access, not a key glyph; copies rows out, not an arrow. An icon only beside a word. Tooltips explain nothing that matters.

05One row per thing, same columns everywhere

Monitors, ways in, marks, fields: a list with the same shape, state first, then what it is, then where it stands, then one action. Open or refused rows come first.

06Facts first, controls second

A card says what is true (4.8% now, was 0.9%; expires in 341 d; behind by 4 rows) before it offers a button. Numbers are mono; the biggest number is the one that decides.

07The bar stays copy-pasteable

key:value in one field, prefilled by cards and crumbs, never replaced by a builder. Scope on a share, a link or a monitor uses the same syntax.

08Panels narrow, never cover

An event, the marks panel, a sheet: they take width from the rows and leave the clock in view. Live pauses while reading and says so. Esc always goes back one step.

09The fence is on the server, the chart is named

A share holds named panels and a derived scope; a page names a panel. Raw params stay allowed within the fence. Rows never leave through a share; ids never leave through aggregates.

10Colour means one thing

Plate white is the mark and the primary action. Red is open, refused, fatal. Amber is paused or slow. Blue and orange are the level stack. Teal is a flag or a share. Nothing else is coloured.

11Empty states are the setup

No data, no marks, no monitors: the page shows the three steps that would fill it, in the layout it will have when full. The page never swaps for a different one.

12Every number is a hunt away

A refusal count, a monitor's value, a link's rate: each is a link to the rows behind it with the query filled in. Toposcope stores projections; the rows stay the proof.
