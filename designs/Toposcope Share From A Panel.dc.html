24d
the code, in three steps, with a preview
960×660
agental-console is ready
Three things to paste. The secret is shown this once.
1The secret, on your backend
TOPOSCOPE_SHARE=[SHARE SECRET]
An environment variable of the app that serves the page. Never in the page.
2Each page load, your backend asks for a ticket
const { ticket } = await fetch( "https://logs.agental.dev/share/v1/tickets", { method: "POST", headers: { authorization: `Bearer ${process.env.TOPOSCOPE_SHARE}` } } ).then((r) => r.json());
A ticket lasts an hour and can only read. Hand it to the page.
3In the page, where the chart goes
<script src="https://logs.agental.dev/embed.js" data-ticket="${ticket}" data-metric="fleet_cpu_seconds" data-split="host" data-range="24h" data-title="CPU by host"></script>
Serve your own copy of embed.js to keep a fallback when Toposcope is down. How
